Sesiapa sahaja (yes, *literally* korang semua) yang nak request untuk tambahkan *windshield* watak anime,, gaming, VTuber, atau apa-apa je watak kegemaran korang, jangan malu-malu!

## ⚠️ Important Updates & Compatibility Notes

Sebelum korang *pull* atau *download* apa-apa dari repo ni, sila take note perkara penting ni:

1. **Version Compatibility:** Kalau korang nak teruskan *stay* atau kekal pakai version **1.48 ke atas**, *go ahead*, silakan! Dipersilakan seikhlas hati.
2. **The 1.59 Meta Shift:** Ada satu *major tea* yang korang kena tahu. Semenjak update sistem skins ETS2 versi **1.59**, struktur fail dan sistemnya dah *rework* habis-habisan—jauh berubah, berbeza, dan langsung tak sama macam era version **1.58 ke bawah**. Jadi, pastikan mod yang korang pasang serasi dengan version game semasa supaya tak *crash* dekat tengah jalan!
